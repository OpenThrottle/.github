# Support

Thanks for using OpenThrottle! Here's how to get help.

## Getting help

- **Questions & how-to** — open an issue on the relevant repository and describe
  what you're trying to do.
- **Bugs** — file a bug report using the repository's issue templates. Include
  reproduction steps, expected vs. actual behavior, and your environment.
- **Feature ideas** — open a feature-request issue and describe the problem
  you're trying to solve, not just the solution.

## Before you file

- Search existing issues first — someone may have already reported it.
- Check the repository's `README.md` and any `docs/` for setup and usage.

## Security

Do **not** report security vulnerabilities in public issues. Follow
[SECURITY.md](./SECURITY.md) for private disclosure.

## Contributing

Interested in contributing? See [CONTRIBUTING.md](./CONTRIBUTING.md) and our
[Code of Conduct](./CODE_OF_CONDUCT.md). A repository may provide its own
repo-specific contribution guide, which takes precedence for that project.
